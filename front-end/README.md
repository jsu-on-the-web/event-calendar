
# Event Calendar
A simple 🗓️ calendar web app for adding and managing 🎆 events.

## Features
- [x] Monthly calendar view
- [ ] Adding events
- [ ] Deleting events
- [ ] Viewing events
- [ ] Filtering and searching for events
- [ ] "Upcoming Events" sidebar

## Tech Stack
### 🖼️ Front End
- React
- Typescript
- CSS
- PostCSS

### 🛠️ Back End
- Spring Boot
- GraphQL
- PostgresSQL
